This second layer turns the project's datasets into an interactive research space: explore matched English and Simplified Chinese questions, inspect Chinese-context examples, and use the same question to compare a documented model response with the dataset's benchmark or reference material.

MATCHED MULTIPLE CHOICE

Global-MMLU-Lite

English and Simplified Chinese versions of evaluation questions matched by sample_id.

  • Best for language-to-language comparison
  • CS vs. CA cultural-sensitivity labels
  • Benchmark answer-key comparison
BILINGUAL OPEN-ENDED

CC-Eval · value alignment

Parallel Chinese and English prompts designed to examine whether responses shift when the same value-oriented question is posed in different languages.

  • Compare response framing across languages
  • Useful for saved model-output analysis
  • Needs a disclosed scoring rubric
CHINESE-CONTEXT TASKS

CC-Eval · cultural context

Separate task families for classical Chinese, folk culture, aesthetics/philosophy, internet slang, and pragmatic intent.

  • Explore meaning beyond literal translation
  • Test indirect intent and cultural references
  • Compare task types without treating them as one score

Important: these datasets should not be collapsed into one accuracy number. Their question formats, reference material, labels, and evaluation purposes differ. The explorer keeps those structures visible.

QUESTION LAB · CONTROLLED MODEL COMPARISON

Ask a fixed question, then compare the response.

This is intentionally a controlled question selector rather than an unrestricted chatbot. Each choice maps to a dataset record so the question, language, reference answer, and eventual model output can be traced back to a source record.

Translation should reveal context, not hide it.

A later version can connect this interaction to the project's multilingual evaluation work: the same text could be represented in the source script, standardized Chinese, pinyin, English, and a documented cultural-context record. That keeps the translation visible as an interpretation rather than treating it as a perfect one-to-one conversion.
