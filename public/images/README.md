# Image demo assets

The image-translation prototype expects these three local photograph assets:

- `chinese-text-1.jpg` — gate inscription
- `chinese-text-2.jpg` — signboard
- `chinese-text-3.jpg` — stone inscription

- `chinese-text-4.jpg` - Is a screenshot taken from https://zh.wikisource.org/wiki/%E8%AB%96%E8%AA%9E/%E9%9B%8D%E4%B9%9F%E7%AC%AC%E5%85%AD

Image 4 acts as a baseline for accuracy between AI interpretation of handwriting versus readable traditional characters given by a site with it's own set of translation.

They are referenced by `index.html` and `script.js`.

These files are project-provided photograph assets and should be kept separate from third-party dataset redistribution. The current prototype uses hand-defined hotspots; the images are not processed by automatic OCR yet.

All phtotography based images were taken by Michelle Clark.
Image location is Jinxi Ancient Town, located in Kunshan, Suzhou, China.
