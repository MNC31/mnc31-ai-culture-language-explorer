# Source datasets

This folder contains complete source datasets used by the AI Culture & Language Explorer.

## Global-MMLU-Lite

Location: `data/global-mmlu-lite/`

This project includes the complete downloaded English (`en`) and Simplified
Chinese (`zh`) Global-MMLU-Lite dataset splits:

- `en_dev.jsonl`
- `en_test.jsonl`
- `zh_dev.jsonl`
- `zh_test.jsonl`

Original source:
https://huggingface.co/datasets/CohereForAI/Global-MMLU-Lite

License:
Apache License 2.0.

Associated paper:
Singh et al. (2024), “Global MMLU: Understanding and Addressing Cultural and
Linguistic Biases in Multilingual Evaluation.”
https://arxiv.org/abs/2412.03304
